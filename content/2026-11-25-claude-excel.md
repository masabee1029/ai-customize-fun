Excelの数式をたどっていて、「このセル、どこから来た数字だっけ」と手が止まったことはありませんか。
結論は、**Claude for Excel（Excelの中で使えるClaudeのアドイン）を入れると、表のことを話しかけて聞けて、「いつもこう整えて」という自分好みの指示も、1回書けば保存できる**、ということです。この記事では、入れ方と使い方、コピペで使える例を紹介します。

**確認日：2026年11月25日**（公式のヘルプで確認。画面や名前は変わることがあります）

**この記事でわかること：** 使える人と環境、入れ方の流れ、仕事でも遊びでも使える聞き方の例、自分好みの指示の書き方、注意点。結論は、**まず1つのブックで「このセルの数字はどう出ている？」と聞いてみる**ことです。

## Claude for Excelとは？ 表のそばにいる相談相手

公式のドキュメントでは、Claude for Excelは「ExcelにClaudeを持ち込むアドイン」と説明されています。開いているブックについて質問したり、エラーの原因を調べたり、モデル（計算の表）を作ったりできます。答えには、**どのセルを見て答えたかの引用**がつき、クリックするとそのセルに移動できます。

使えるのは、公式ページでは**Pro・Max・Team・Enterpriseのプラン**とされています。無料プランでは使えるかどうかが書かれていないので、ご自身のプランは、公式の案内でご確認ください。

動く環境は、次のとおりです（公式に書かれている内容）。

| 環境 | 使えるか |
|---|---|
| Excel on the web（ブラウザ版） | 使える |
| Windows（Microsoft 365のサブスクリプション版） | 使える（ビルドの条件あり） |
| Mac | 使える（バージョンの条件あり） |
| Excel 2016・2019（買い切り版） | 使えない |
| iPad・Android | 使えない |

会社のPCで使うときは、**アドインを入れてよいかを、先に会社の決まりで確かめて**ください。

## 入れ方の流れ

自分で入れる場合は、3つの手順です。

1. MicrosoftのAppSourceにある「Claude for Microsoft 365」のページを開き、「Get it now」で入れる
2. Excelを開き、アドインを有効にする（Macは「ツール」→「アドイン」、Windowsは「ホーム」→「アドイン」）
3. Claudeのアカウントでサインインする

会社全体で入れる場合は、管理者がMicrosoft 365の管理センターから配布します。あなたが個人で入れられない場合は、情報システムの担当者に聞いてみてください。

## 仕事で使う聞き方の例

使い方は、「話しかけるだけ」です。公式の例にそった、コピペで使える聞き方を紹介します。【　】の中は、ご自分のブックに合わせて書き換えてください。

- 【C42】のセルの数字は、どの数字から計算されていますか。順番に説明してください
- この表の【粗利率】は、どの前提で決まっていますか
- 【まとめ】シートの【#REF!】のエラーの原因を探して、直し方を提案してください
- 【割引率】を【8%】に変えたとき、数式のつながりを壊さずに、関係するセルも更新してください
- 【この売上表】を、並べ替えて、【担当者】ごとに絞り込んでください

たとえば、前任者から引き継いだ工程表で、どこをいじると全体が変わるのかが分からない場面です。「この表で、納期の日付はどのセルで決まっていますか」と聞くと、答えに**セルへのリンク**がつくので、自分の目で確かめながら進められます。

## 遊びで使う聞き方の例

Excelは、仕事だけの道具ではありません。次のような使い方も、楽しいです。

- 【家計簿】から、「今月つい使いがちな項目」を3つ、理由つきで教えてください
- 【推しのグッズの購入リスト】を、予算内に収まる組み合わせにしてください。数字を変えたら、合計が自動で変わるようにしてください
- 【家族旅行の持ち物表】を、場面ごとに色分けしてください

ここで気をつけたいのは、**数字を変えるときは、先に「どのセルを、どう変えるか」を言葉で確認してもらう**ことです。

## 自分好みの指示を保存する

公式のドキュメントには、アドインの設定画面の「Instructions（指示）」欄に書くと、**Excelでの会話すべてに効く**と書かれています。使い方の例として、「数字には3桁の区切りを付ける」「見出しの行は必ず太字にする」といった書式のきまりや、通貨・地域の好み、くり返し出る仕事の背景があげられています。

たとえば、次のように書いておくと便利です。

| 書く内容 | 例 |
|---|---|
| 書式のきまり | 数字には3桁の区切りを付けてください。見出しの行は太字にしてください |
| 言葉づかい | 説明は、専門用語を使わず、短い文で書いてください |
| 仕事の背景 | 私は製造業の生産管理で、工程表と在庫表をよく使います |
| 安全のきまり | 既存のデータを書き換える前に、必ず確認してください |

この指示は、Excelの中だけで効きます。PowerPointやWordの指示とは別です。Claude全体の覚え方は[Claudeのメモリの使い方](claude-memory-howto.html)、仕事ごとにまとめる方法は[Claudeのプロジェクトの使い方](claude-projects-howto.html)、手順をくり返し使いたいときは[Claudeのスキルの使い方](claude-skills-howto.html)も参考にしてください。

## 向かない人・注意点

公式のドキュメントには、次の注意が書かれています。

- **最終の提出物や、監査にかかわる計算は、人の確認なしで使わない**
- **機密性の高い情報や、規制のあるデータは、管理の仕組みなしに入れない**
- **マクロ（VBA）とデータテーブルには、まだ対応していません**
- **外から届いたファイルには、隠された指示が入っていることがあります。** 信頼できるブックだけで使い、危ない操作の確認が出たら、よく読んでから進めてください
- 使った内容は、Anthropicに送られます。会社の決まり（情報の持ち出し・利用規程）を先に確かめ、社外秘・個人情報は入れないでください
- 修正の前には、**コピーを取ってから**始めると安心です

「マクロを書いてほしい」「完全に自動で、確認なしに更新したい」という使い方は、いまは向きません。
