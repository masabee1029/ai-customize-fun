ChatGPTと声で話してみて、「声の感じが、もう少し自分好みだったらいいのに」と思ったことはありませんか。
ChatGPTの音声と声のカスタマイズは、3つの設定で整います。「設定 → 音声」で**声を選ぶ**、**言語を決める**、そして会話の中で**話し方を頼む**。公式ヘルプには、Arbor・Breeze・Coveなど9種類の声と、日本語向けの「ひまり」「りんどう」が載っていて、どれも設定画面から切り替えられます。
この記事では、2026年10月28日に公式ヘルプで確かめた手順と、通勤中に使う場面・家で遊ぶ場面の頼み方を紹介します。

**確認日：2026年10月28日**（公式のヘルプで確認。画面や名前は変わることがあります）

## ChatGPTの音声のしくみ｜Live・Advanced・Standardの3つ

公式ヘルプ「ChatGPT Voice」によると、音声には3つのモードがあり、「設定 → 音声（Voice）」で切り替えられます。使えるモードは、プラン・地域・アプリのバージョン・保護者による管理の設定で変わります。

| モード | 公式ヘルプの説明 | 向いている場面 |
|---|---|---|
| Live | 聞くと話すを同時に行え、割り込みや会話のやりとりが自然。ウェブ検索とメモリが使え、文字や画像も同じチャットで扱える。動画や画面共有には対応しない | 通勤中の相談、家族との雑談のような「会話」 |
| Advanced | 以前のリアルタイム音声。スマホアプリでの動画や画面共有が必要なときに使う | カメラで物を見せながら聞きたいとき |
| Standard | 話した内容を文字に起こしてから返事を作る、順番交代型 | 静かな場所で、ゆっくり正確に話したいとき |

音声は「チャットの中」で動きます。話しながら返事を文字で追えて、話せない場所では文字を打ち、前のやりとりを見返せる、と公式ヘルプに書かれています。電車の中で声を出せないときは、同じチャットで文字に切り替えればよい、ということです。

はじめて使う人からは、「音声にすると、設定したカスタム指示が効かなくなる気がする」という声も聞きます。公式ヘルプには、**プリセットのパーソナリティ（プロフェッショナル・フレンドリーなど）は、現時点ではLiveには適用されない**と書かれています。その代わり、会話の中で「もっとゆっくり」「短く答えて」と頼めば、その会話の中では変えられます。設定で決めたいことと、会話で頼むことを、分けて考えるのがコツです。

## 設定1：声を選ぶ｜9種類と日本語向けの2つ

声の選び方は、公式ヘルプの手順でこうなっています。

1. 「設定」を開く
2. 「音声（Voice）」を選ぶ
3. 「声（Voice）」から好きなものを選ぶ

選べる声は、執筆時点の公式ヘルプで9種類です。それぞれの性格づけも、ヘルプの表現をもとにしています。

| 声の名前 | 公式ヘルプの性格づけ | こんな人に |
|---|---|---|
| Arbor | のびやかで万能 | まず迷ったらこれ |
| Breeze | 生き生きとして真面目 | 元気に話したい |
| Cove | 落ち着いて率直 | 仕事の相談を淡々と |
| Ember | 自信があって前向き | 背中を押してほしい |
| Juniper | 開放的で明るい | 雑談が楽しい |
| Maple | 陽気で率直 | はっきり言ってほしい |
| Sol | 賢くてリラックス | 夜のひと息に |
| Spruce | 穏やかで肯定的 | 不安なときに |
| Vale | 明るくて好奇心旺盛 | 一緒に調べ物を |

Liveでは、言語ごとの追加の声もあります。日本語向けは**「ひまり（Himari）」と「りんどう（Rindō）」**の2つです。日本語で話すなら、この2つを試してみると、発音の自然さが変わって聞こえるかもしれません。表示される声は地域やアカウントで変わる、と公式ヘルプにあります。

会話の途中で声を変えると、同じチャットの中で新しい音声の通話が始まります。試すなら、一度話し終えてから切り替えるほうが、流れが切れません。

遊びの使い方として、家族で「今日はどの声にする？」と選ぶのも楽しいものです。子どもが寝る前の「今日あったこと」をSpruceの声で聞いてもらい、あなたの朝の予定確認はCoveで淡々と。声を替えるだけで、同じChatGPTが別の相手のように感じられます。

## 設定2：言語を決める｜聞き取りを安定させる

公式ヘルプには、「音声が間違った言語を検出する場合、いちばんよく話す言語を選ぶと、聞き取りがより正確になる」とあります。手順はこうです。

1. 「設定」を開く
2. 「音声（Voice）」→「言語（Language）」を選ぶ
3. ふだん話す言語を選ぶ

日本語で話しているのに英語で返ってくる、英語の単語を混ぜると途中で言語が切り替わる、というときは、ここを「日本語」にしておくと落ち着きます。会話の中で「英語で話して」と頼めば、その場では別の言語にも切り替えられます。

英語の練習に使いたい人は、言語の設定は日本語のままにして、会話の中で「ここからは英語で、ゆっくり話してください。私が間違えたら、日本語で一言だけ直してください」と頼む形が、聞き取りも安定しておすすめです。

## 設定3：話し方を頼む｜会話の中でできること

公式ヘルプによると、Liveでは**会話の中で、口調・速さ・返事のスタイルを変えてほしいと頼める**ようになっています。「速く」「ゆっくり」も頼めますが、「1.2倍速」のような細かい再生速度の指定は、執筆時点ではできません。

コピーして使える頼み方を、場面ごとに並べます。【　】はあなたの言葉に置き換えてください。

**通勤中・仕事の前に**

- 返事は3文以内で、結論を先に言ってください
- 今日の予定を言うので、優先順位を一緒に決めてください。質問は1つずつにしてください
- 【例：明日の生産会議】で話す内容を、私が話すので、要点を3つにまとめて言い直してください
- ゆっくり、落ち着いた声で話してください。電車の中で聞いています

**家で遊ぶ・家族と**

- 【例：小学2年生】に分かる言葉で、ゆっくり話してください
- 絵本を読むような調子で、【例：宇宙を旅する猫】の短いお話を作ってください。途中で「どうする？」と聞いてください
- 今日の晩ごはんのメニューを3つ提案してください。1つ選んだら、作り方を手順ごとに区切って、私が「次」と言ったら続けてください
- クイズを出してください。【例：日本の都道府県】の問題を、1問ずつ、答えを言うまで待ってください

**声の調子そのものを**

- もう少し元気に話してください
- 落ち着いた、ささやくような調子にしてください
- 相づちを減らして、要点だけ言ってください

こうした頼み方は、その会話の中で効きます。次の会話でも同じ調子にしたいなら、「カスタム指示」に書いておくのが近道です。カスタム指示の書き方は[ChatGPTのカスタマイズのやり方](chatgpt-customize-howto.html)に、カスタム指示とメモリの使い分けは[ChatGPTのカスタム指示とメモリの違い](chatgpt-custom-instructions-vs-memory.html)にまとめています。パーソナリティはLiveには適用されない、という公式の記載があるので、音声の調子は会話の中で頼む、と覚えておくと迷いません。

## プラン別の音声の上限（2026年10月28日・公式ヘルプ）

音声の使える時間は、プランで違います。公式ヘルプ「ChatGPT Voice」の表から、個人向けの部分を抜き出しました。チャットの中のLiveの利用は、直近24時間の枠で数えられ、上限に近づくと通知が出ます。

| プラン | Liveの利用 |
|---|---|
| 無料 | GPT-Live-1.1 Quipへの限定的なアクセス（上限は変わることがある） |
| Go | GPT-Live-1.1 Quipで3時間 |
| Plus | GPT-Live-1.1で3時間 |
| Pro（月100ドル） | GPT-Live-1.1で15時間 |
| Pro（月200ドル） | GPT-Live-1.1で無制限（不正利用防止の安全対策あり） |

GoとPlusは同じ3時間ですが、使うモデルが違います（GoはQuip）。通勤の往復で毎日30分話すなら、週に2時間半。無料で足りるか、Goの3時間が欲しいかは、ここで見当がつきます。GoとPlusで増えるもの・増えないものは、公式の料金ページとヘルプで確かめてから選ぶと迷いません。

会社のことを音声で話すときは、会社の決まり（情報の持ち出し・利用規程）を先に確かめ、社外秘や個人情報は口にしないようにしてください。文字で入力するときと同じ線引きです。

## 向かない人・注意点

- **動画や画面共有を使いたい人**：Liveは動画と画面共有に対応していません。スマホアプリでAdvancedに切り替える必要があります
- **プリセットのパーソナリティを音声にも効かせたい人**：執筆時点では、パーソナリティはLiveに適用されません。会話の中で頼む形になります
- **再生速度を細かく決めたい人**：「速く」「ゆっくり」は頼めますが、倍速の数値指定はできません
- **声の種類**：表示される声は地域やアカウントで変わります。この記事の9種類と日本語向けの2つが、あなたの画面に全部出ない場合もあります

もう1つ。音声での答えにも、文字と同じで間違いが混ざることがあります。公式ヘルプにも、日付・時間・場所に関わる質問は特に確かめるように、と書かれています。会議の時間や締め切りのような大事なことは、文字でも見直すのが安心です。
