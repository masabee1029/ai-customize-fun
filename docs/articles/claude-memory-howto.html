Claudeのメモリ機能の使い方｜自分のことを覚えてもらう

Claudeのメモリ機能は、会話の中からあなたの役割や進めている仕事、好きな伝え方を覚えて、次の会話に活かしてくれる機能です。

メモリでClaudeが覚えること

公式ヘルプでは、Claudeは会話が終わってからまとめるのではなく、会話の途中で、話題ごとに分けて メモリを保存すると説明しています。たとえば「締め切りが金曜に動いた」と話すと、次の会話ではもうそれを知っている、という使い心地です。

公式ヘルプに挙げられている、覚える内容の例です。

  • あなたの役割、進めている仕事、仕事の背景
  • 仕事と暮らしで関わる人や場所
  • 伝え方の好みや、仕事の進め方
  • 技術的な設定や、書き方の好み
  • 進行中の作業のくわしい中身

反対に、公式ヘルプによると、健康、人種・民族、宗教、政治、性自認など、個人的でデリケートな話題は はじめの設定では保存しません。何度も説明しなおすのが手間なときだけ、「メモリに機密トピックを含める」をオンにして含めることを選べます。また、政府が発行するID番号、犯罪歴、金融の口座番号、在留資格などは、頼んでも保存されないと書かれています。

使えるプラン（公式ヘルプで確かめた内容）

プランメモリのはじめの状態
Free・Pro・Maxウェブ・Claude Desktop・Claude Mobile（最新版）で、はじめからオン
Team・Enterprise組織のオーナーが使えるかどうかを決め、各メンバーが自分でオンにするまではオフ

料金ページ（claude.com/pricing）でも、無料のプランの内容に「会話をまたぐメモリ」が並んでいます。

メモリをオン・オフする場所

オンにする

  1. 左下のイニシャルを選び、「設定」→「Your Claude」へ進む（古い設定画面では「設定」→「メモリ」）
  2. 「チャットからメモリを生成する」をオンにする

止める・消す

同じ場所のスイッチを押すと、公式ヘルプによれば次の2つから選べます。

選びかた何が起きるか
メモリを一時停止今あるメモリは残したまま、使うことも新しく作ることも止まる。止めている間の会話は、あとでオンに戻してもメモリに入らない
メモリをリセットプロジェクトのメモリもふくめて、すべてのメモリを消す。取り消しはできない

「しばらく覚えてほしくないだけ」のときは一時停止、「最初からやりなおしたい」ときはリセット、と使い分けると迷いません。リセットは元に戻せないので、先に覚えている内容を見ておくと安心です。

同じ「設定」→「Your Claude」の画面では、「チャットを検索して参照する」のスイッチで、Claudeが過去のチャットを探して使うかどうかも切りかえられます。公式ヘルプでは、過去のチャットの検索は有料のプラン（Pro・Max・Ultra・Team・Enterprise）で使える機能と案内しています。

覚えている内容を見る・直す

Claudeがあなたのことを何と覚えているかは、いつでも確かめられます。

  1. 「設定」→「Your Claude」へ進む（古い設定画面では「設定」→「メモリ」）
  2. 「あなたのメモリ」の横の「管理」を選ぶ
  3. 「トピック」の下に並んだ項目を選んで読む
  4. 直したいときは編集のアイコン、消したいときは「削除」を選ぶ

1つのトピックを直すと、そのあとのすべての会話に反映されると公式ヘルプに書かれています。

設定画面を開かなくても、会話の中で頼むだけで直せます。コピーして使える言い方です（【　】をあなたの言葉に）。

  • これを覚えておいてください：わたしは【印刷会社の生産管理】を担当しています
  • 覚えている内容を直してください：【担当】は【品質管理】に変わりました
  • 【　】のことは忘れてください
  • わたしについて覚えていることを、箇条書きで見せてください

月に1回くらい「管理」を開いて、古くなった内容を直しておくと、答えのずれが少なくなります。

1回だけ覚えてほしくないとき

メモリをオンのままでも、会話ごとに覚えない形を選べます。公式ヘルプでは、方法が2つ案内されています。

方法始め方チャット履歴メモリ
そのチャットだけメモリをオフ新しいチャットで、メッセージ欄の「+」→「メモリ」をオフにしてから最初のメッセージを送る残る（ほかの会話から検索で見つけられる）使わない・保存しない
シークレットチャットプロジェクトの外で新しいチャットを始め、右上のゴーストのアイコンを選ぶ残らない使わない・保存しない

覚えておきたい点を、公式ヘルプからまとめました。

  • 「+」→「メモリ」のオフは、最初のメッセージを送る前 に選ぶ。送ったあとは変えられないので、変えたいときは新しいチャットを始める
  • メモリをオフにしたチャットは、タイトルの横に線の入ったメモリのアイコンが出る
  • シークレットチャットは、Free・Pro・Max・Ultra・Team・Enterpriseのすべてのプランで使える
  • シークレットチャットの画面は黒いふちどりと「シークレットチャット」の表示で見分けられ、右上の「x」で閉じる
  • シークレットチャットは、プライバシーの設定でモデルの改善を許可していても、Claudeの改善には使われない
  • シークレットチャットは履歴には残らないが、はじめの設定では30日間保持される

家族へのサプライズの相談や、一度きりのちょっとした調べものはシークレットチャット。あとで見返したいけれど、メモリには入れたくない相談は「+」→「メモリ」のオフ。この使い分けで、覚えてほしいことだけが残ります。

プロジェクトごとのメモリと、ほかのAIからの引っこし

公式ヘルプによると、プロジェクトにはそれぞれのメモリ があります。プロジェクトの中では、そのプロジェクトのメモリと、プロジェクトの外のチャットのメモリを使い、ほかのプロジェクトのメモリは使いません。

プロジェクトのメモリを完全に分けたいときは、プロジェクトのページの「メモリ」で「アカウントメモリを使用」をオフにします。たとえば「取引先A社の見積もり」のプロジェクトは分けておき、ふだんの会話にA社の話がまざらないようにする、という使い方ができます。プロジェクトの作り方は Claudeのプロジェクトの使い方 にまとめています。

ほかのAIで覚えてもらっていた内容は、Claudeに移せます。公式ヘルプの手順は次のとおりです（この機能は試験的で、開発中と書かれています）。

  1. 「設定」→「Your Claude」で「インポートを開始」を選ぶ
  2. 画面に出る頼み方を、今まで使っていたAIに貼りつけて、覚えている内容を書き出してもらう
  3. 書き出した文章をClaudeの入力欄に貼り、「メモリに追加」を選ぶ

公式ヘルプでは、Claudeのメモリは仕事に関わる話題を中心に覚えるように作られていて、仕事に関係のない個人的な情報は残らない場合があると説明しています。書き出した文章から、入れたくない内容を先に消しておくと安心です。ChatGPTのメモリとカスタム指示の違いは ChatGPTのカスタム指示とメモリの違い で紹介しています。

覚えてもらうと楽になること（仕事と遊び）

メモリに向いているのは、何度も説明している「あなたの前提」です。仕事と遊びの例を並べました。

場面覚えてもらうと楽なこと伝え方の例
仕事担当と、ふだん使う道具覚えておいてください：わたしは【生産管理】で、【Excel・Teams】をよく使います
仕事好きな答え方覚えておいてください：答えは結論から、箇条書き【3つ】まで
仕事社内でよく使う言葉の意味覚えておいてください：【刷版】は【印刷用の版】のことです
遊び家族の好き嫌い覚えておいてください：子どもは【ピーマン】が苦手です
遊び趣味と好きな作品覚えておいてください：休日は【キャンプ】、好きなアニメは【　】です

仕事の話をするときは、まず会社のルールを確かめて、取引先の名前や社外秘の数字、だれかの個人情報は、メモリにも会話にも入れない形にしておくと安心です。担当や好きな答え方のような「あなた自身の前提」だけを覚えてもらえば、毎朝の自己紹介がなくなり、残業の30分を減らす小さな積み重ねになります。

いつも守ってほしい決まりは「Claudeの指示」、会話の中で自然に増えていく情報はメモリ、と分けると整理しやすくなります。指示とスキル、コネクタもふくめた全体の使い分けは Claudeのカスタマイズのやり方 へ。Claudeを始めたばかりのあなたは Claudeの使い方 初心者向け もどうぞ。
