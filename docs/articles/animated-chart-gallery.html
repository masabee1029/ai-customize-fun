動くグラフは「見る順番」を案内してくれる

止まったグラフは、全部の棒や数字が同時に目に入ります。動くグラフは、見る人の目を「ここから見てください」と順番に案内してくれます。
参考にしたのは、データを動くグラフの動画にしてくれるサービス「iArt.ai」のアニメーションチャートのページです。そこでは、棒グラフのレース、売上の折れ線、数字が数え上がるカウンター、動く円グラフが代表として並んでいます。このサイトでも、その4つの考え方を、あなたが会社のPCや家でそのまま試せる形でお届けします。

形動き伝わること向いている数字
棒グラフ棒が左からのびる大きさのちがい2〜8個の比べ
カウンター数字が0から数え上がる1つの数字の大きさ合計・上限・達成
円グラフ（ドーナツ）円が順番に回り込む全体の中の割合2〜4個の内訳
折れ線グラフ線が左から描かれる時間の流れの変化月ごと・年ごとの推移

形は「数字の仕事」で選ぶと迷いません。比べたいなら棒、1つの数字を見せたいならカウンター、内訳なら円、移り変わりなら線です。

1. 数字が数え上がる「カウンター」

1つ1つの数字の大きさを見せたいときは、カウンターがいちばん目にとまります。たとえば、Microsoft 365 Copilotで自分用のエージェント（決まった仕事を任せるAIの助手）を作るとき、入力欄ごとの文字数の上限は次のとおりです。

「指示は8,000文字まで書ける」と数字が大きく数え上がると、「最初の5行は気軽に書いて大丈夫」と感じてもらいやすくなります。作り方は Copilotのエージェントの作り方 にまとめています。

AIへの頼み方の例です。【　】をあなたの数字に入れ替えて使えます。

  • 次の3つの数字を、0から数え上がるカウンターにしたHTMLを1つのファイルで作ってください
  • 数字：【名前 30】【説明 1,000】【指示 8,000】、単位は【文字】
  • 数え上がる時間は1.5秒、最後はぴったり指定の数字で止めてください。数字は1つも変えないでください
  • 動きを減らす設定の人には、最初から最後の数字を表示してください

2. 割合が回り込む「円グラフ（ドーナツ）」

全体の中の割合を見せたいときは、円グラフです。真ん中を空けたドーナツ型にすると、すっきり見えます。
下は、このサイトの記事をカテゴリ別に数えた内訳です（この記事を公開した2026年10月23日の時点）。

円グラフは、分ける数を4つくらいまでにすると読みやすくなります。5つ以上になるときは、小さいものを「その他」にまとめるのがコツです。色だけで見分けなくてよいように、横に名前と数字も並べています。

  • 次の内訳を、ドーナツ型の円グラフにして、1つずつ時計回りに回り込むアニメーションのHTMLを作ってください
  • 内訳：【項目A 6】【項目B 2】【項目C 2】【項目D 2】
  • 円の横に、色・項目名・数・割合（％）の一覧を出してください。割合は四捨五入で整数に
  • 色は4色まで。色の見分けがつきにくい人でも読めるよう、名前と数字は必ず文字でも出してください

3. 線が描かれていく「折れ線グラフ」

月ごとの移り変わりを見せたいときは、折れ線グラフです。線が左から右へ描かれていくと、「いつ上がって、いつ下がったか」を、物語のように追えます。
下は、説明のために作ったサンプルの数字です（実在の会社の数字ではありません）。

最後の点の上にだけ数字を出しているのは、全部の点に数字を書くと線が読みにくくなるからです。ほかの点は、点の上にマウスを置くと数字が出ます。下の「数字を表で見る」を開くと、全部の数字を表で確かめられます。

  • 次の月ごとの数字を、左から右へ線が描かれていく折れ線グラフのHTMLにしてください
  • 数字：【4月 820】【5月 860】【6月 790】【7月 910】【8月 880】【9月 1,020】、単位は【個】
  • 線は細め（2px）、点は丸。最後の点の上にだけ数字を表示し、ほかの点はマウスを置くと数字が出るようにしてください
  • 縦の目盛りは0から始めてください

4. もう一度、棒グラフを自分の数字で

最初に見た棒グラフは、いちばん使いやすい形です。会議の資料なら「先月と今月」「AラインとBライン」のような2〜8個の比べに向いています。

  • 次の数字を、棒が左から順番にのびる横棒グラフのHTMLにしてください
  • 数字：【項目と数字を、カンマで区切って並べる】、単位は【　】
  • 棒の右に数字を出し、0から数え上がって、指定の数字でぴったり止めてください
  • 数字は1つも変えず、四捨五入もしないでください。作ったら、使った数字を表にして最後に見せてください

最後の1行がとても大切です。AIが作ったグラフの数字を、元の表と見比べて確かめられるからです。詳しいコツは AIでアニメーションするグラフを作る にまとめています。

数字をずらさないための3つのコツ

動くグラフは目にとまりやすいぶん、数字がまちがっていると、それも目立ってしまいます。次の3つを添えるだけで、安心して使えます。

  1. 数字はあなたが渡す：「だいたいの数字で」と頼まず、表の数字をそのまま貼る
  2. 「数字は1つも変えないで」と書く：四捨五入や単位の変更も、しないように頼む
  3. 最後に表で見せてもらう：グラフに使った数字を表にしてもらい、元の表と見比べる

会社の数字を使うときは、AIに入れてよい情報かどうか、会社の決まり（情報の持ち出しや利用のルール）を先に確かめておくと安心です。社外秘の数字は、項目名を「A・B・C」に置きかえて形だけ作り、数字はあとから自分で入れる方法もあります。
