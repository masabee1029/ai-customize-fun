# AIを楽しくカスタマイズしよう

https://masabee1029.github.io/ai-customize-fun/

- `content/*.md` … 記事（書式は build.py の先頭）
- `python3 build.py` … docs/ を生成（GitHub Pages は main:/docs）
- `site.json` … サイト名・色・おすすめ商品・トップの見出し（hero_html / extra_css）。カテゴリ: ChatGPT / Gemini / Claude / Copilot / 楽しみ方
- `topics.txt` … 自動投稿の記事ネタ（Googleの検索候補から）
- 参考: 『人を動かす』の発信ルール、iArt.ai のアニメーションチャートのページ（大きな見出し・入力欄・vs・動く数字・3ステップ）
